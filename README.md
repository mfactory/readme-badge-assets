# Mortgage Factory README badge assets

Public generated status images used by Mortgage Factory repository READMEs so they render in web and mobile GitHub clients.

This repository contains no application source, credentials, or deployment artifacts. A fine-grained token restricted to this repository with Contents write updates each generated image from its private source repository. Badge refreshes do not deploy applications.

- `mfactory-site/readme-status.svg` — generated by `mfactory/mfactory-site`

The images and their history are public. Never add secrets, applicant information, or other private data.
